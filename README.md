# 🌐 Ethical Tech 101

## 📌 Project Overview
**Ethical Tech 101** adalah sebuah landing page edukatif yang bertujuan untuk memperkenalkan konsep **etika dalam teknologi**.  
Latar belakang proyek ini berangkat dari kenyataan bahwa perkembangan teknologi yang pesat sering kali menimbulkan permasalahan etis, seperti kebocoran data pribadi, bias algoritma, dan kesenjangan digital.  

Proyek ini secara spesifik membahas tiga aspek penting dalam etika teknologi:
- **Cybersecurity** → menekankan pentingnya keamanan digital, integritas data, dan praktik higienis online.  
- **Blockchain** → menunjukkan potensi blockchain untuk kebaikan sosial, seperti transparansi rantai pasok, identitas digital yang aman, dan sistem voting yang adil.  
- **Antropologi** → memberikan perspektif budaya dan sosial, agar teknologi tetap selaras dengan nilai-nilai kemanusiaan dan relevan dalam konteks masyarakat.  

Pendekatan yang digunakan adalah **penyampaian informasi singkat yang padat dan mudah dipahami**, serta menyediakan **tautan ke sumber akademik/profesional** untuk eksplorasi lebih lanjut. Dengan demikian, landing page ini berfungsi sebagai pintu masuk (entry point) bagi masyarakat untuk memahami etika teknologi dari sudut pandang multidisipliner.

---

## 🛠️ Technologies Used
Proyek ini menggunakan teknologi web dasar yang dipilih karena ringan, mudah dipahami, dan sesuai kebutuhan untuk membangun sebuah landing page edukatif:

 Bahasa & Framework:
   - Python → digunakan untuk scripting dan interaksi dengan IBM Granite.
   - HTML5 + Tailwind CSS → digunakan untuk membangun antarmuka landing page.
   - **JavaScript (minimal)** → digunakan hanya untuk mendukung animasi sederhana (fade-in) agar konten lebih interaktif tanpa membebani performa.  

 Platform & Tools:
   - GitHub → sebagai repositori kode, dokumentasi proyek, serta version control.
   - Google Colab → menjalankan model AI (IBM Granite) dan eksperimen coding.
   - Netlify → untuk deployment landing page agar dapat diakses publik.
   - Duplicate → digunakan untuk cloning atau menyalin project dasar sehingga bisa dikembangkan sesuai kebutuhan tim.
   
 Pemilihan teknologi ini sesuai kebutuhan proyek yang tidak membutuhkan backend, database, atau framework kompleks. Fokus utamanya adalah **penyajian informasi** yang mudah diakses di berbagai perangkat.

 Alasan pemilihan teknologi:
   - Python dipilih karena kompatibel dengan IBM Granite.
   - HTML & Tailwind CSS dipilih untuk membuat UI yang ringan, modern, dan mudah di-deploy.
   - GitHub memastikan kolaborasi dan penyimpanan aman.
   - Google Colab memudahkan eksperimen AI tanpa butuh resource lokal besar.
   - Netlify memberi hosting gratis, cepat, dan mudah diintegrasikan.
   - Duplicate mempercepat pengembangan dari template yang sudah ada.

## ✨ Features
Fitur utama dari landing page **Ethical Technology 101** adalah:

1. **Konten Edukatif Terstruktur**  
   - Menyajikan informasi tentang etika teknologi dengan pembagian tema yang jelas: cybersecurity, blockchain, dan antropologi.  
   - Menggunakan bahasa sederhana agar mudah dipahami oleh audiens umum.  

2. **Referensi Akademik & Profesional**  
   - Menyediakan tautan ke artikel jurnal dan sumber terpercaya untuk memperdalam pengetahuan.  
   - Membantu audiens yang ingin belajar lebih lanjut dari sumber valid.  

3. **Desain Responsif**  
   - Menggunakan Tailwind CSS untuk memastikan tampilan rapi di perangkat desktop maupun mobile.  

4. **Animasi Interaktif**  
   - Efek **fade-in** pada setiap section membuat pengalaman membaca lebih engaging tanpa mengganggu performa.  

5. **Bagian Kontak**  
   - Tersedia email untuk komunikasi lebih lanjut.  

Cara kerja fitur selaras dengan tujuan proyek: memberikan informasi singkat, lalu mengarahkan pengguna ke sumber yang lebih dalam, sehingga berfungsi sebagai **portal etika teknologi**.

## 🤖 AI Support Explanation
Dalam proses pengembangan proyek ini, **AI berperan sebagai asisten pengembang** dengan fungsi berikut:
- **Bantuan Penulisan Kode** → AI membantu menyusun kerangka HTML, CSS, dan integrasi Tailwind CSS dengan lebih cepat, sehingga menghemat waktu dan meminimalisasi error teknis.  
- **Perbaikan Styling & UX** → AI memberikan saran terkait warna, tipografi, animasi, dan layout agar tampilan landing page lebih rapi dan menarik.  
- **Penyusunan Konten** → AI mendukung dalam merangkum topik etika teknologi (cybersecurity, blockchain, antropologi) menjadi poin-poin singkat yang mudah dipahami.  

- **ChatGPT**  
  Digunakan untuk:
  - Merancang ide awal dan konsep proyek.  
  - Mengatasi error ketika terjadi saat pengembangan.  
  - Membantu memahami cara penggunaan platform seperti GitHub, Colab, dan Netlify.  
  - Menyusun konten `README.md`.  

- **Gemini**  
  - Membantu menghasilkan kode (code generation).
  - Digunakan untuk membuat skrip agar bisa berkomunikasi dengan IBM Granite lewat bahasa pemrograman.

- **IBM Granite**  
  - Digunakan di Google Colab untuk menjalankan semua tugas yang berhubungan dengan pengkodean.
  - Menjadi engine utama dalam pemrosesan kode Python.  

Dampak nyata penggunaan AI:
- Proses ideasi dan dokumentasi jadi lebih cepat dan terstruktur.
- Generasi kode dan debugging lebih efisien.
- Penggunaan model Granite memungkinkan eksperimen coding langsung di Colab tanpa keterbatasan resource lokal.
- Membantu memahami praktik coding dasar secara praktis sambil tetap memegang kontrol kreatif pada isi konten.
